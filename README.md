# Paceline – Running Shop Website

A responsive website for Paceline, a Glasgow running shop, built for the
DCS Web Cluster frontend task.

## Live Demo
https://your-site.netlify.app

## Pages
- Home (`home.html`)
- About (`about.html`)

## Features
- Fully responsive (phone, tablet, desktop)
- Mobile hamburger menu with keyboard and screen reader support
- Newsletter form with email validation
- Semantic HTML, visible focus styles, alt text on images
- Lazy-loaded images and map

## Built With
HTML5, CSS3 (Grid, Flexbox, custom properties), vanilla JavaScript

## How to Run Locally
1. Download or clone the repository:
```bash
   git clone https://github.com/Babyka007/paceline-website.git
```
2. Open the `paceline-website` folder.
3. Double-click `about.html` to open it in your browser.
   (No installation or build step is needed.)
